# Tulshi Shop Login System

This project is a Flask-based web application for the Tulshi Shop login system.

## Project Structure

The project follows a standard Flask application structure:

```
d:\shop\
│
├── app.py                  # Main Flask application file (Backend logic)
├── requirements.txt        # Python dependencies
├── README.md               # Project documentation
│
├── static\                 # Static assets (CSS, JS, Images)
│   ├── css\
│   │   └── style.css       # Main stylesheet
│   ├── js\
│   │   └── script.js       # Client-side JavaScript
│   └── images\
│       └── 1770743257917.png  # Logo image
│
└── templates\              # HTML Templates
    └── index.html          # Login page template
```

## How to Run

1.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Run the Application**:
    ```bash
    python app.py
    ```

3.  **Access the Login Page**:
    Open your web browser and navigate to: `http://127.0.0.1:5000`
